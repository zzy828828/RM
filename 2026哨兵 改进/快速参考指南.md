# 当前代码快速参考指南

本文以当前工作区源码为准，固定行号可能随修改变化，因此只引用文件、函数和宏名。

## 操作速查

### 遥控器

| 输入 | 当前功能 |
|---|---|
| 右摇杆 | 底盘前后、左右平移 |
| 左摇杆 | 云台 Yaw、Pitch |
| 左拨杆上 | 底盘跟随云台，云台使能 |
| 左拨杆中 | 小陀螺，云台使能 |
| 左拨杆下 | 通常无力；与右拨杆同时向下时进入键鼠模式 |
| 右拨杆下 | 摩擦轮关闭、停止发射 |
| 右拨杆中 | 摩擦轮开启、拨弹停止 |
| 右拨杆上 | 摩擦轮开启、连续拨弹 |

### 键鼠

左右拨杆都向下后：`Ctrl+Z` 小陀螺、`Ctrl+X` 跟随云台、`Ctrl+C` 无力；`WASD` 移动，鼠标移动控制云台，`F` 掉头约 180°，`Q/E` 开关摩擦轮，鼠标左键正向拨弹，右键反向拨弹。

`Z/X/C/V` 同时是 1–4 号舵机 PWM 增加键，`Shift+Z/X/C/V` 为减小键。因此 `Ctrl+Z/X/C` 会与舵机 1–3 调节发生冲突。

## 小陀螺退出回正

关闭小陀螺并进入跟随模式时，新增同向解缠与 yaw 指令加速度限制（默认12 rad/s²，每2 ms最多变化0.024 rad/s）。默认回正速度上限9.5 rad/s，刹停规划10 rad/s²并预留100 ms反馈滞后距离；可能需要额外一圈。详细补丁和验收边界见 [修改说明](doc/底盘同向回正修改说明.md)。

## 当前关键参数

### 拨弹轮

| 宏 | 当前值 | 用途 |
|---|---:|---|
| `CAN_TRIGGER_MOTOR_ID` | `0x207` | 拨弹轮反馈 ID |
| `CAN_GIMBAL_ALL_ID` | `0x1FF` | Yaw/Pitch/拨弹轮组控制 ID |
| `TRIGGER_SPEED` | `7.0f` | 保留的单发函数速度；当前输入路径未进入单发状态 |
| `CONTINUE_TRIGGER_SPEED` | `7.0f` | 正向连续拨弹速度 |
| `READY_TRIGGER_SPEED` | `5.0f` | 准备速度常量 |
| 鼠标右键反向速度 | `-4.0f` | 退弹/清卡，由 `shoot.c` 直接赋值 |
| `BLOCK_TRIGGER_SPEED` | `1.0f` | 堵转速度阈值 |
| `BLOCK_TIME` | `700` | 堵转累计周期 |
| `REVERSE_TIME` | `500` | 自动反转周期 |
| `FULL_COUNT` | `18` | 编码器圈数展开参数 |
| `MOTOR_ECD_TO_ANGLE` | `0.0000213052887206339f` | 编码器到输出角度换算 |

速度 PID 使用 `TRIGGER_ANGLE_PID_KP/KI/KD = 800.0/0.5/0.0`，最大输出和积分限幅分别由 `TRIGGER_READY_PID_*` 与 `TRIGGER_BULLET_PID_*` 控制。

### 摩擦轮

| 宏 | 当前值 |
|---|---:|
| `FRIC_OFF` | `1000` |
| `FRIC_DOWN` | `1600` |
| `FRIC_UP` | `1800` |
| `SHOOT_FRIC_PWM_ADD_VALUE` | `100.0f` |

当前斜坡上限初始化为 `FRIC_DOWN = 1600`，所以正常启动目标是 1600；`FRIC_UP` 暂未用于活动控制路径。两个斜坡输出均达到 1500 后，状态机才允许拨弹。

## CAN 数据路径

当前 `CHASSIS_CAN` 和 `GIMBAL_CAN` 都定义为 `hcan1`。工程虽然初始化了 CAN2，但本模块不使用 CAN2。

```text
拨弹轮反馈 0x207
  -> HAL_CAN_RxFifo0MsgPendingCallback()
  -> motor_chassis[6]
  -> get_trigger_motor_measure_point()
  -> shoot_control_loop()
  -> shoot_control.given_current
  -> CAN_cmd_gimbal(yaw, pitch, shoot, rev)
  -> CAN1 / 0x1FF / 字节 4–5
```

反馈帧：字节 0–1 编码器、2–3 转速、4–5 给定电流、6 温度。组控制帧：0–1 Yaw、2–3 Pitch、4–5 拨弹轮、6–7 预留电机电流。

## 当前射击状态

活动输入路径为：

```text
STOP
  -> READY_FRIC
  -> 两个摩擦轮 PWM >= 1500
  -> READY_BULLET
  -> 左键或右拨杆上：CONTINUE_BULLET（正转）
  -> 右键：CONTINUE_BULLET（-4.0f 反转）
```

枚举和 `shoot_bullet_control()` 仍保留单发状态，但 `shoot_set_mode()` 当前不会因遥控器或鼠标输入进入 `SHOOT_BULLET`，所以不能把它写成可用操作。

拨弹轮从离线恢复时，程序会重置摩擦轮斜坡并强制进入 `SHOOT_STOP`，需要重新操作右拨杆或按 `Q` 启动。

## 更换拨弹轮电机检查表

1. 确认反馈 CAN ID、控制组 ID、帧格式和总线。
2. 确认编码器分辨率、减速比和 `MOTOR_ECD_TO_ANGLE`。
3. 按新电机允许范围调整 PID 输出限幅。
4. 调整正转、反转、堵转阈值和反转时长。
5. 先架空机构验证反馈方向，再低速验证闭环和卡弹恢复。
6. 检查 `TRIGGER_MOTOR_TOE` 离线状态与断电恢复逻辑。

## 校准手势速查

两个拨杆都向下，先“双摇杆下内八”保持 2 秒，然后在 20 秒内保持第二个手势 2 秒：陀螺仪为下外八、云台为上外八、底盘 ID 为上内八。

详细操作与安全提示见 [readme.md](readme.md)。
