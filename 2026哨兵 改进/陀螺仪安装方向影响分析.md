# 陀螺仪安装方向影响分析

## 结论

BMI088 的机械安装方向必须与 `application/INS_task.c` 中的 `BMI088_BOARD_INSTALL_SPIN_MATRIX` 一致。安装方向改变而矩阵不改，会造成轴交换或符号错误，严重时使云台形成正反馈并快速失控。

零漂校准只能补偿静态偏置，不能修复安装方向错误。

## 当前坐标转换

当前矩阵为：

```text
[ 0  1  0 ]
[-1  0  0 ]
[ 0  0  1 ]
```

在 `imu_cali_slove()` 中，陀螺仪和加速度计使用同一矩阵，因此软件坐标关系为：

```text
software_x =  sensor_y + offset_x
software_y = -sensor_x + offset_y
software_z =  sensor_z + offset_z
```

也就是 X/Y 轴旋转 90°，Z 轴方向保持不变。

## 安装不一致的影响

### 姿态解算

- 绕某一机械轴转动时，软件可能把变化解释成另一轴。
- 某轴符号反转时，角速度和角度方向会相反。
- 加速度重力方向错误会破坏 Pitch/Roll 修正。
- 当前磁力计周期读取被注释，Yaw 更依赖陀螺仪积分，方向错误会持续累积。

### 云台控制

云台绝对角度模式直接使用 INS Yaw/Pitch 和角速度反馈。若传感器方向与电机正方向不匹配，可能出现：

- 指令向右，反馈却判定为向左。
- Pitch 抬头时软件认为在低头。
- 速度环减振项变成助推项。
- 云台顶住限位、抖动或快速连续旋转。

### 底盘控制

底盘姿态由 INS 角度与云台相对角共同计算。方向错误会影响跟随云台角度、小陀螺时的全局方向保持以及模式切换稳定性。

### 自动校准

云台校准依次驱动 Pitch 两端和 Yaw 两端，并使用轴向角速度判断是否稳定。轴映射错误可能造成步骤无法结束、错误记录限位或持续顶死。

## 正确处理方法

### 优先方案：恢复既定安装方向

按照开发板和整机机械设计的既定方向安装，保持当前矩阵不变。这种方式风险最低，也最容易与原始电机方向和调参保持一致。

### 必须旋转安装时：修改矩阵

1. 明确传感器坐标系到车体坐标系的刚体旋转。
2. 为每个软件轴选择唯一的传感器轴和符号。
3. 确认矩阵为正交矩阵，行列互相垂直，元素通常为 `-1/0/1`。
4. 陀螺仪和加速度计使用同一安装矩阵。
5. 修改后重新执行陀螺仪零漂与云台限位校准。

不能通过反复试符号直接开启闭环；应先用只读数据验证轴向。

## 安全验证步骤

1. 架空底盘、取出弹丸，限制云台运动范围并准备立即断电。
2. 暂不开启云台闭环，保持设备静止，确认三轴角速度接近零。
3. 单独绕车体 X、Y、Z 正方向缓慢转动，确认只有对应软件轴明显变化且符号正确。
4. 静止时确认重力主要落在预期轴，翻转设备后符号反向。
5. 低电流使能单轴云台，确认电机运动会让误差减小。
6. 再逐步恢复完整云台、底盘跟随和自动校准。

若云台出现快速加速、持续顶限位或剧烈高频抖动，应立即断电，不要依赖遥控器切换模式来抢救。

## 与零漂校准的区别

| 项目 | 安装矩阵 | 零漂校准 |
|---|---|---|
| 修正对象 | 坐标轴交换和方向 | 静止时的常量偏置 |
| 是否改变轴 | 是 | 否 |
| 是否能修复反向 | 能，前提是矩阵正确 | 不能 |
| 修改后是否要重校准 | 是 | 校准本身即生成偏置 |

安装方向问题必须在矩阵或机械安装层面解决，不能用更大的 PID、死区或零漂值掩盖。
