# 摩擦轮控制方式分析

本文已按当前源码复核。摩擦轮采用 PWM 开环控制，不是 CAN 电机。

## 硬件与定时器

| 项目 | 当前实现 |
|---|---|
| 定时器 | TIM1 |
| 摩擦轮 1 | TIM1 CH1 |
| 摩擦轮 2 | TIM1 CH2 |
| TIM1 分频 | `167` |
| TIM1 周期 | `19999` |
| PWM 基准 | 约 50 Hz，计数单位约 1 μs |

底层驱动位于 `bsp/boards/bsp_fric.c`：`fric1_on()` 和 `fric2_on()` 写比较值，`fric_off()` 将两个通道设为 `FRIC_OFF`。

## 当前 PWM 参数

`bsp/boards/bsp_fric.h` 中的实际值为：

```c
#define FRIC_UP   1800
#define FRIC_DOWN 1600
#define FRIC_OFF  1000
```

`shoot_init()` 使用 `FRIC_DOWN` 作为两个斜坡的上限，因此当前活动控制路径的启动目标是 1600，不是 1800。`FRIC_UP` 目前没有被射击状态机直接使用。

两个摩擦轮斜坡输出都达到 1500 后，状态机才从 `SHOOT_READY_FRIC` 进入 `SHOOT_READY_BULLET`，允许拨弹轮动作。

## 操作输入

| 输入 | 结果 |
|---|---|
| 右拨杆下 | `SHOOT_STOP`，摩擦轮斜坡下降至 1000 |
| 右拨杆中 | 启动摩擦轮，不拨弹 |
| 右拨杆上 | 启动摩擦轮；达到就绪阈值后连续正向拨弹 |
| `Q` | 键鼠模式下启动摩擦轮 |
| `E` | 键鼠模式下关闭摩擦轮 |
| 鼠标左键 | 摩擦轮就绪后连续正向拨弹 |
| 鼠标右键 | 摩擦轮就绪后以 `-4.0f` 速度反向拨弹 |

键盘摩擦轮控制由一个保持标志接管；左拨杆离开下位后，该标志清除并恢复右拨杆控制。

## 控制数据流

```text
右拨杆或 Q/E
  -> shoot_set_mode()
  -> SHOOT_STOP / SHOOT_READY_FRIC
  -> ramp_calc()
  -> fric1_ramp.out / fric2_ramp.out
  -> fric1_on() / fric2_on()
  -> TIM1 CH1/CH2
  -> 电调
  -> 无刷电机与摩擦轮
```

这条路径只有输出，没有转速、电流或温度反馈。

## 离线检测

`detect_task.h` 的检测列表包含 DBUS、底盘电机、Yaw/Pitch、拨弹轮、板载传感器、裁判系统、RM IMU 和 OLED，但没有摩擦轮检测项。

因此：

- 不安装摩擦轮不会触发离线报警。
- 摩擦轮或电调故障不会被软件自动识别。
- `fric_pwm1/2` 只代表命令值，不能证明电机实际转动。
- 拨弹轮 `TRIGGER_MOTOR_TOE` 的在线状态不能替代摩擦轮状态。

拨弹轮从离线恢复时，`shoot_control_loop()` 会重置摩擦轮斜坡并强制停止射击；这是一项联动恢复策略，不是摩擦轮自身的反馈检测。

## 与 CAN 电机对比

| 特性 | 当前摩擦轮 | CAN 电机 |
|---|---|---|
| 控制接口 | PWM | CAN |
| 反馈 | 无 | 编码器、速度、电流、温度 |
| 控制闭环 | 软件侧开环 | 可做速度/位置闭环 |
| 离线检测 | 不支持 | 支持 |
| 当前输出范围 | 1000–1600 | 取决于电调协议和软件限幅 |

## 更换硬件

保持 PWM 电调时，需要确认新电调接受 50 Hz、1000–1600 μs 范围，并重新验证启动目标、双轮方向和斜坡速度。

改成 CAN 电机时，需要增加反馈 ID、接收解析、组控制发送、速度闭环和离线检测；同时删除或隔离现有 TIM1 PWM 路径。

## 安全注意事项

调试前取出弹丸并清空摩擦轮周围区域。修改 PWM 上限后应从低值逐步验证；不能因为命令达到 1600 就认定摩擦轮已经达到安全发射速度。
