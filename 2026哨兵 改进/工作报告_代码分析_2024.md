# 步兵机器人代码与文档核对报告

> 文件名沿用原 2024 报告名称；内容已于 2026-09-16 按当前源码重新核对。

## 工作目标

统一仓库内的操作说明和技术分析，使遥控器、键鼠、校准、CAN、摩擦轮与拨弹轮描述和当前代码一致。

## 当前代码结论

### 控制映射

- 右摇杆控制底盘平移，左摇杆控制云台。
- 左拨杆控制底盘/云台模式：上为跟随云台，中为小陀螺，下通常为无力。
- 右拨杆控制发射：下为停止，中为仅开摩擦轮，上为连续拨弹。
- 两个拨杆都向下时，`Ctrl+Z/X/C` 分别选择小陀螺、跟随云台、无力。
- 当前用户输入没有启用单发状态。

### CAN

- `CHASSIS_CAN` 和 `GIMBAL_CAN` 均指向 `hcan1`。
- 底盘组控制 ID 为 `0x200`。
- Yaw/Pitch/拨弹轮反馈 ID 为 `0x205/0x206/0x207`，组控制 ID 为 `0x1FF`。
- CAN2 虽已初始化，但当前电机宏不使用 CAN2。

### 拨弹轮

| 参数 | 当前值 |
|---|---:|
| `TRIGGER_SPEED` | `7.0f` |
| `CONTINUE_TRIGGER_SPEED` | `7.0f` |
| `READY_TRIGGER_SPEED` | `5.0f` |
| 鼠标右键反转速度 | `-4.0f` |
| `BLOCK_TRIGGER_SPEED` | `1.0f` |
| `BLOCK_TIME` | `700` |
| `REVERSE_TIME` | `500` |

`SHOOT_BULLET` 和单发函数仍存在，但活动输入逻辑只进入连续拨弹状态。

### 摩擦轮

| 参数 | 当前值 |
|---|---:|
| `FRIC_UP` | `1800` |
| `FRIC_DOWN` | `1600` |
| `FRIC_OFF` | `1000` |

摩擦轮使用 TIM1 CH1/CH2、约 50 Hz PWM。当前斜坡目标是 `FRIC_DOWN=1600`，输出达到 1500 后允许拨弹。摩擦轮没有反馈和离线检测。

### 校准

统一第一步为双摇杆下内八 2 秒。第二步：陀螺仪下外八、云台上外八、底盘 ID 上内八，均保持 2 秒并在第一步后的 20 秒窗口内完成。

### 惯导

BMI088 通过数据就绪中断和 SPI DMA 更新。当前安装矩阵是：

```text
[ 0  1  0 ]
[-1  0  0 ]
[ 0  0  1 ]
```

IST8310 初始化存在，但周期磁力计读取被注释。

## 已修正文档问题

1. 左右拨杆职责曾写反。
2. 底盘 ID 校准第二手势曾误写为下外八，现改为源码实际判断的上内八。
3. 文档曾把云台与拨弹轮写成 CAN2，现改为 CAN1。
4. 摩擦轮旧参数 `1400/1320/1000` 已更新为 `1800/1600/1000`。
5. 拨弹速度旧值 `10/15` 已更新为 `7/7`。
6. 删除“当前可单发”的操作说明，并明确单发仅为保留代码。
7. 补充鼠标右键反向拨弹、拨弹轮离线恢复和摩擦轮 1500 就绪阈值。
8. 补充 `Ctrl+Z/X/C` 与舵机 `Z/X/C` 的按键冲突。
9. 移除容易失效的固定代码行号，改用函数和宏定位。

## 当前已知风险

- `Ctrl+Z/X/C` 会同时增加舵机 1–3 PWM。
- 摩擦轮开环运行，命令值无法证明实际转速。
- `FRIC_UP=1800` 当前不在活动斜坡路径中。
- 单发状态保留但不可从用户输入触发。
- 磁力计读取被注释，Yaw 长时间稳定性主要依赖陀螺仪积分。

## 建议后续修改

1. 把整车模式快捷键或舵机快捷键改到不冲突的按键。
2. 明确是否需要恢复单发入口；不需要时删除死代码和相关枚举。
3. 若需要 1800 PWM，显式修改斜坡上限并重新做发射安全测试。
4. 明确 CAN2 是否保留；不使用时可简化初始化和接线说明。
5. 若需要磁航向修正，恢复并验证 IST8310 数据读取后再加入姿态融合。
