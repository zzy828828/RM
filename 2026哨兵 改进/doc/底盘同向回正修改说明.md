# 关闭小陀螺后同向回正：修改说明

日期：2026-09-16。代码仅修改 `application/chassis_task.c`；原 PID 增益、行为选择、位移变换、SWING 生成、自转软启动和电流功率限制均保留。

## 1. 根因分析

### (a) 方向：对普通零目标回正成立，不能泛化为 PID 自带最短路径

`chassis_set_contorl()`（源码实际函数名）中的跟随分支原来计算 `-PID_calc(pid, q, target)`，其中 q 是云台相对底盘关节角。普通回正 target=0，q∈[-π,π]，故比例输出的底盘速度符号与 q 相同；q<0 时会请求负方向。若退出前自转指令为正，这就是反向回正的代码原因。

PID 本身没有最短路径算法，只是 set-ref。当 SWING 的 target 非零，原始差值甚至可能超过 π，不能说它“总走最短路径”。约一半角度区间对应相反的比例方向，但实际发生比例受关掉时角度分布和 D 项影响。

证据：`chassis_task.c/chassis_set_contorl()`、`gimbal_task.c/gimbal_feedback_update()`、`pid.c/PID_calc()`。

### (b) 指令阶跃成立；实际功率尖峰需要波形

速率分支直接把自转输出赋给 wz_set，跟随分支直接把负 PID 输出赋给 wz_set，没有两者之间的速度轨迹。最坏可从 +9.5 跳到 -12 rad/s；按 2 ms 周期，等效指令斜率为 -10750 rad/s²。

`chassis_vector_to_mecanum_wheel_speed()` 再把旋转量按 `MOTOR_DISTANCE_TO_CENTER=0.223 m` 加到四轮速度上。这一跳变对应每轮约 4.7945 m/s 的旋转分量变化；轮速 PID 可能饱和。是否真的瞬时超过 80 W、峰值多少，不能仅从源码证明，需裁判功率或电源测量。

### (c) 陈旧历史造成 D 项脉冲成立；实际急刹幅度需波形

`PID_calc()` 的位置式 D 项是 Kd×(本次误差-上次误差)，不除以 dt。自转时该角度 PID 不更新，两个角度模式又共用它；模式切换原本不清状态。因此旧 error[0] 会成为切换首帧的 error[1]，影响 Dout。KI=0 时不能把问题归因于本轮新增积分饱和；error[2] 并不直接参与位置式当前 D 项。

只执行 PID_clear() 仍会产生 Kd×新误差。补丁清零后将 error[0..2] 全部预装为本次误差，首帧 Dout=0。

### 旧“300 ms 跟随软启动”

它只缩放 target，target=0 时不起缓冲作用。更直接的问题是 `chassis_infantry_follow_gimbal_yaw_control()` 在检查进入沿之前就把 `chassis_last_frame_in_follow_gimbal` 写成当前状态，进入检测条件实际上不成立。补丁把过渡放在真正的 wz_set 生成处，没有改动这段旧逻辑及 SWING 波形。

## 2. 修改方案

```text
AUTO_SPIN：保持原速率输出和 1200 ms 软启动
  -> 模式切换函数检测 last_auto_spin && new_mode==FOLLOW_GIMBAL
  -> INIT：保存上一帧 wz_set、确定 S、选择可刹停的同向等价目标
           清 PID 并预装新误差，首帧原样输出上一帧 wz_set
  -> DIRECTED：持续解缠关节角和实时目标
               旧 PID -> 同向限制/低速残差修正 -> 刹停包络 -> 指令斜率限制
  -> 对齐误差<=0.03 rad，指令和实测速度<=0.2 rad/s，持续100 ms
  -> FOLLOW：正常环形误差 PID，重新预装历史，继续斜率限制
  -> 离开跟随模式：取消过渡，执行原新模式
```

设 q=云台全局角-底盘全局角，target 为行为层输出的关节角目标。底盘正速度使 q 减小。因此 e=rad_format(target-q)，底盘所需角位移是 -e。

取 S=sign(退出前最后一帧 wz_set)，建立 d=-S×e；d<0 时加 2π，使 d 位于 [0,2π)。给 PID 的持续误差为 e'=-S×d，不再逐帧把 e' 包回 [-π,π]。

每帧：
```text
d += S × (rad_format(q-q_last) - rad_format(target-target_last))
```
所以枪口变化和 SWING 仍更新目标，±π 环绕不会把目标改成反方向。只累计退出之后的角度，长时间自转的历史圈数不进入状态。

入口按 max(|wz_set|, S×实测wz) 估计所需刹停角：
```text
d_stop = v²/(2×10) + v×(0.002+0.10) + 0.05
```
若最近同向目标不足以刹停，向后选择等价目标，增加整圈数 ceil((d_stop-d)/(2π))。正常 v<=9.5 rad/s 时最多加一圈；实测超速或运动目标下不能保证这一圈数上限。

运行时用 d_eff=max(0,|d|-0.10×朝目标运动的实测速度) 提前刹车；包络 v_safe=sqrt((a×dt)²+2a×d_eff)-a×dt，a=10 rad/s²。PID 增益保持12/0/15，包络上限为9.5 rad/s；最终指令每2 ms最多变化0.024 rad/s。

d<0 但仍在0.03 rad容差内，且指令/实测速度均不超过0.2 rad/s时，允许至多0.3 rad/s的反向残差修正。若已错过窗口 d<-0.03，重新选择同向可刹停目标，不反向高速追回。这可能增加额外圈数，不能声称无限制工况下总是仅多转一圈。

没有先发 STOP 或先把速度清零再释放的过渡。离线取消、无力指令为保护例外，具有更高优先级。

新增状态约24字节加1字节标志（最终对齐/分配以链接器为准）。每周期固定数量的浮点运算，含一次 sqrtf；ceilf 只在初次选择或错过目标时执行。没有阻塞、动态分配、打印或新任务。

实际执行了本机 Keil V5.06 update 6 的 `standard_tpye_c` 构建，最终日志为0错误、0警告。Code=74908、RO-data=7412、RW-data=1204、ZI-data=57828。这只说明编译链接通过，尚未烧录、测量任务耗时/栈余量或验证实机。

另做了独立的离线标量指令模型检查：两种符号、72个退出角度、0.01/1/8.5/9.5 rad/s四档初速，在理想跟踪及30/60/100 ms一阶跟踪滞后下共2304组，模型内收敛且无重复选圈，指令步进不超过0.024 rad/s。150 ms滞后的额外576组压力工况中566组在12秒内未捕获，出现重复选圈。这表明默认100 ms余量并非任意机械系统的稳定性保证。模型不是实际 C 固件执行，也不含四轮电流、功率限制、轮胎打滑和机构弹性。

## 5. 边界与风险

### 圈数和耗时不能无条件承诺

单纯同向解缠的第一次目标 d∈[0,2π)，但9.5 rad/s时 d_stop=5.5315 rad。距离不足时增加2π，正常静止枪口/实测不超9.5的入口规划总角度小于11.8147 rad，而不一定小于2π。

“至多多转2π”只能解释为在最近同向目标上额外增加一圈；相对最短路径，额外角度可能大于2π。要对所有退出角度保证总行程<=2π，同时保持同向、首帧连续和有限减速度，在物理上不可行。

一圈按9.5 rad/s匀速是661 ms，但不能拿这个值作为含减速的总时间。仅按12的限速从9.5降到0至少792 ms；按规划减速度10是950 ms，再叠加匀速行程、反馈余量和100 ms稳定确认。固定枪口标量模型在额定初速下约1.23–2.09秒，工程上可先按约1.3–2.3秒观察，不是实机时限保证。

### 动态操作

vx/vy 的原路径、坐标变换和统一软启动未改。平移或按方向键仍即时进入原逻辑；四轮共用速度上限和功率预算，所以带平移时实际回正可能更慢。

左摇杆/鼠标改变枪口和 SWING 改变关节目标时，目标增量持续进入解缠状态，没有冻结输入。但方向锁定和限速会造成底盘追踪延迟；不可能既强制同向回正，又要求底盘无延迟跟随任意反向枪口运动。持续移动目标时不存在有限回正时间保证；收敛到容差的验收应在枪口和SWING目标停止或足够缓慢后进行。

普通跟随接管后保持12 rad/s²斜率限制，这也是显式的响应变化。原SWING波形生成不变，但实际底盘响应受限；不能声称动态表现完全不劣化。

### 相邻路径与保护

AUTO_SPIN->NO_MOVE保持原零速度指令和主动停止，不执行同向找枪口；这条路径仍可能产生制动电流跃变，需要另行定义软停需求。当前物理左拨杆下还会使云台无力，通常最终覆盖为ZERO_FORCE；NO_MOVE按可达的新行为或未来调用讨论。

AUTO_SPIN->ZERO_FORCE立即沿原RAW零电流路径退出，不为平滑回正延迟无力保护。遥控离线的最终零电流发送保留。跟随期间任一底盘电机或Yaw反馈离线时，取消解缠历史，yaw指令归零；恢复后从零指令限速进入普通跟随，不沿旧多圈目标追赶。原AUTO_SPIN内的离线重新软启动代码未改。

没有修改四轮速度PID、功率缩放、热量限制、堵转逻辑。指令平滑减少一种冲击来源，并不保证四轮电流或实际功率没有尖峰。

### 回退

`CHASSIS_ALIGN_ENABLE=0` 可快速对照禁用过渡，但共享PID清理和正常跟随环形误差仍生效。完整回退应在核对补丁上下文且无重叠用户修改后，反向应用 `doc/patches/chassis_spin_exit.patch`，重新构建再烧录；不能直接使用不明版本旧bin。不要以覆盖整个文件的方式回退。

## 6. 实机验证清单

前置：可靠架空底盘、卸下弹丸、检查云台运动空间及线束、准备驱动断电。首轮架空确认符号，后续在受控地面验证功率；架空不能代表带载功率或刹停性能。

建议记录5个内部量，使用调试器或已有遥测，避免2 ms循环打印：

1. `chassis_align.state`：INIT/DIRECTED/FOLLOW。
2. `chassis_align.remaining`：带方向的连续剩余角。
3. `chassis_move.wz_set`：切换前符号S、指令连续性及斜率。
4. `chassis_move.wz`：编码器运动学估计的实际角速度。
5. `chassis_move.chassis_angle_pid.Dout`：首帧/交接微分项。

用裁判功率或电源侧记录辅助判断80 W限制；仅上述内部量无法证明功率。

步骤与判据：

- 原地自转稳定后，在q约±0.1、±π/2、±(π-0.01)处切换。首帧指令等于最后自转指令，后续相邻指令差<=0.024 rad/s；容差外不得请求-S速度。
- 观察跨±π时remaining连续，不突变约2π；入口增加整数圈是规划事件，应与状态INIT对应。
- 观察DIRECTED期间反向残差指令幅度<=0.30 rad/s，发生前误差已在0.03 rad内且指令/实测速度<=0.20 rad/s。
- 普通接管须连续100 ms满足误差与速度阈值；模式首帧和接管后的第一次PID调用Dout=0。
- 边平移边自转退出，以及退出同时WASD/右摇杆改变平移。确认平移方向和软启动保留，记录四轮饱和和功率是否延长回正。
- 退出同时改变左摇杆/鼠标、按住或松开Ctrl/SWING。确认目标持续更新；允许方向锁定期间的跟随延迟，停止目标后应收敛。
- 短暂自转软启动尚未结束时退出，再次进入自转；检查原1200 ms三次软启动保留。
- 分别使用拨杆和Ctrl+Z/X/C切换，检查无力优先级、取消过渡和再次进入行为。
- 验证遥控离线、Yaw/底盘电机离线恢复及AUTO_SPIN自身离线重软启动。不能沿离线前旧角度继续追赶。
- 若反复增加整圈、超过预计时长仍不收敛、实际速度反向或功率仍尖峰，停止带载测试，依据实测延迟调整LAG/BRAKE，不能把重复绕圈当作通过。

## 7. 信息缺口

源码已足够确定本次符号和软件入口，无需等待答复才能提供补丁。实机参数确认还缺：

1. 满速退出时wz_set到实测wz的主要滞后与减速曲线，尤其是否超过100 ms规划余量。
2. 80 W读数的采样周期、功率测量位置，以及是否包含再生制动或其他负载。
3. 能否接受为平滑刹停跳过最近同向对齐点并额外转一圈，以及SWING/枪口动态追踪的延迟。
4. 通常退出小陀螺时枪口最大转动速度，以及带平移时四轮速度饱和程度。

以上影响实机验收，不改变已经确认的代码根因。
