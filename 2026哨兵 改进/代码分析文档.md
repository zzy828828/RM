# 机甲大师全向轮步兵机器人代码分析

本文以当前工作区源码为准。为避免代码增删后行号失效，定位统一使用文件名、函数名和宏名。

## 1. 平台与硬件

- MCU：STM32F407IGHx，168 MHz。
- 操作系统：FreeRTOS，通过 CMSIS-RTOS 创建任务。
- 底盘：4 个 M3508/C620，X 型麦轮。
- 云台：Yaw、Pitch 电机。
- 发射：两路 PWM 摩擦轮和 1 个 CAN 拨弹轮。
- 惯导：BMI088；IST8310 初始化但磁力计读取在主循环中被注释。
- 人机输入：DBUS/SBUS 遥控器，同时携带鼠标和键盘数据。

## 2. 任务结构

`Src/freertos.c` 当前创建以下任务：

| 任务 | 优先级 | 主要职责 |
|---|---|---|
| `INS_task` | Realtime | BMI088 采集、温控、姿态解算 |
| `gimbal_task` | High | 云台闭环、射击控制调用、云台组 CAN 发送 |
| `chassis_task` | AboveNormal | 底盘模式、运动学、功率限制、底盘组 CAN 发送 |
| `calibrate_task` | Normal | 陀螺仪、云台和底盘 ID 校准 |
| `detect_task` | Normal | 设备在线/离线判断 |
| `test_task` | Normal | 蜂鸣器错误提示 |
| `servo_task` | Normal | 四路舵机 PWM 键盘调节 |
| 其他任务 | Normal/Low | LED、OLED、裁判系统、USB、电压检测 |

## 3. 遥控器与键鼠

`application/remote_control.c` 将 18 字节 DBUS 帧解析为 5 个通道、2 个三档开关、鼠标和 16 位键盘掩码。通道 4 和鼠标滚轮当前未参与控制。

### 3.1 通道映射

| 数据 | 物理输入 | 用途 |
|---|---|---|
| `ch[0]` | 右摇杆左右 | 底盘左右平移 |
| `ch[1]` | 右摇杆上下 | 底盘前进/后退 |
| `ch[2]` | 左摇杆左右 | 云台 Yaw |
| `ch[3]` | 左摇杆上下 | 云台 Pitch |
| `ch[4]` | 侧拨轮 | 未使用 |
| `s[0]` | 左拨杆 | 云台和底盘模式 |
| `s[1]` | 右拨杆 | 摩擦轮和拨弹 |

### 3.2 拨杆模式

左拨杆上：底盘跟随云台；中：小陀螺；下：通常无力。两个拨杆同时向下时，代码转入键盘模式保持逻辑，由 `Ctrl+Z/X/C` 选择小陀螺、跟随云台和无力。

右拨杆下：停止射击；中：仅启动摩擦轮；上：摩擦轮就绪后连续拨弹。

### 3.3 键鼠

- `WASD`：底盘平移。
- 鼠标移动：云台 Yaw/Pitch。
- `F`：云台转向约 180°。
- `Q/E`：开/关摩擦轮。
- 鼠标左键：连续正向拨弹。
- 鼠标右键：以 `-4.0f` 速度反向拨弹。
- `Ctrl`：跟随模式下的摆动动作。

`servo_task` 同时把 `Z/X/C/V` 定义为四路舵机 PWM 增加键，把 `Shift+Z/X/C/V` 定义为减小键。因此 `Ctrl+Z/X/C` 会同时调节舵机 1–3，是需要修复的输入冲突。

## 4. CAN 架构

`application/CAN_receive.h` 当前定义：

```c
#define CHASSIS_CAN hcan1
#define GIMBAL_CAN  hcan1
```

因此底盘、Yaw、Pitch 和拨弹轮都通过 CAN1。CAN2 虽然初始化，但这组电机代码没有使用它。

| 对象 | 反馈 ID | 发送方式 |
|---|---:|---|
| 底盘 M1–M4 | `0x201`–`0x204` | 组控制 `0x200` |
| Yaw | `0x205` | 组控制 `0x1FF` 字节 0–1 |
| Pitch | `0x206` | 组控制 `0x1FF` 字节 2–3 |
| 拨弹轮 | `0x207` | 组控制 `0x1FF` 字节 4–5 |

反馈帧使用 DJI 电调常见格式：编码器、转速、电流、温度。

## 5. 发射控制

### 5.1 摩擦轮

摩擦轮使用 TIM1 CH1/CH2 的约 50 Hz PWM。当前值：`FRIC_OFF=1000`、`FRIC_DOWN=1600`、`FRIC_UP=1800`。

斜坡在 `shoot_init()` 中以 1600 为上限初始化，因此活动路径的目标是 1600。两个输出均达到 1500 后才允许拨弹。摩擦轮没有反馈，也没有离线检测。

### 5.2 拨弹轮

当前关键参数：

| 参数 | 值 |
|---|---:|
| `CONTINUE_TRIGGER_SPEED` | `7.0f` |
| 鼠标右键反转速度 | `-4.0f` |
| `BLOCK_TRIGGER_SPEED` | `1.0f` |
| `BLOCK_TIME` | `700` |
| `REVERSE_TIME` | `500` |
| PID `Kp/Ki/Kd` | `800.0/0.5/0.0` |

`trigger_motor_turn_back()` 在低速堵转持续达到阈值后切换速度方向一段时间。手动负速度会直接执行，不进入自动堵转判断。

### 5.3 状态机实际入口

当前输入路径为 `SHOOT_STOP -> SHOOT_READY_FRIC -> SHOOT_READY_BULLET -> SHOOT_CONTINUE_BULLET`。枚举中的 `SHOOT_BULLET` 和 `shoot_bullet_control()` 仍保留，但 `shoot_set_mode()` 不会由当前遥控器或鼠标输入进入该状态，因此用户层面没有可用的单发操作。

拨弹轮从离线恢复时，程序会重新初始化摩擦轮斜坡并强制停止发射，等待重新启动。

## 6. 云台与底盘

云台正常工作在 `GIMBAL_MOTOR_GYRO` 模式，使用 INS 绝对角和轴向角速度。鼠标 Pitch 输入增加了一阶低通滤波。

底盘提供：无力、停止、跟随云台、小陀螺等行为。当前小陀螺目标角速度为 `9.5 rad/s`，进入模式时使用 1200 ms、三次幂曲线软启动；平移速度增加后，自转速度在约 `8.5–9.5 rad/s` 之间调整。

云台进入校准、静止或无力状态时会命令底盘停止；云台校准或无力时也会停止射击。

自转退出到跟随云台的 yaw 指令现在通过 `chassis_task.c/chassis_follow_yaw_command()`：持续解缠同向剩余角、基于刹停距离选择等价目标、清理并预装PID历史、限制速度及每帧指令变化。普通跟随接管后保留斜率限制；保护退出不等待回正。既有自转及位移软启动、SWING目标生成和功率控制未修改。完整参数、源码补丁及动态目标限制见 [修改说明](doc/底盘同向回正修改说明.md)。

## 7. BMI088 与姿态解算

BMI088 通过数据就绪中断触发 SPI DMA。原始陀螺仪和加速度计先使用安装旋转矩阵

```text
[ 0  1  0 ]
[-1  0  0 ]
[ 0  0  1 ]
```

转换到车体坐标，再叠加零漂，经过 AHRS 输出 Yaw/Pitch/Roll。云台和底盘都直接使用这些结果，因此机械安装方向与矩阵必须一致。

## 8. 校准

校准由 `application/calibrate_task.c` 管理，并把结果写入 Flash。

两个拨杆向下时，先保持双摇杆下内八 2 秒，再在 20 秒窗口内保持：

- 下外八 2 秒：陀螺仪零漂校准，持续约 20 秒。
- 上外八 2 秒：云台自动限位校准。
- 上内八 2 秒：发送底盘电机快速设置 ID 命令。

云台自动依次寻找 Pitch 两端和 Yaw 两端；不是由操作员手动拖动云台完成。

## 9. 离线检测

检测列表包含 DBUS、4 个底盘电机、Yaw、Pitch、拨弹轮、板载陀螺仪/加速度计/磁力计、裁判系统、RM IMU 和 OLED。摩擦轮不在列表中。

蜂鸣器任务遍历到 `REFEREE_TOE` 之前，因此其声音告警范围不包含裁判系统以及列表中更靠后的 RM IMU、OLED；OLED 和 USB 状态输出仍可显示相应状态。

## 10. 已知问题

1. `Ctrl+Z/X/C` 与舵机 1–3 增加 PWM 冲突。
2. README 旧版本中的左右拨杆说明与代码相反，现已按源码更正。
3. 单发函数保留但没有活动输入入口。
4. `FRIC_UP=1800` 未进入当前摩擦轮斜坡路径，正常目标仍为 1600。
5. CAN2 已初始化但底盘和云台宏都绑定 CAN1，接线与文档必须以该宏为准。
6. IST8310 初始化并参与数据结构，但主循环的实际磁力计读取被注释。

## 11. 修改与测试建议

- 所有运动测试先架空底盘、卸下弹丸并限制电流。
- 修改电机方向、IMU 矩阵或编码器方向后，先逐轴验证反馈符号，再开启闭环。
- 修改发射参数时分别验证摩擦轮启动、拨弹正反转、堵转恢复和离线重启。
- 优先消除舵机快捷键与整车模式快捷键的冲突。
